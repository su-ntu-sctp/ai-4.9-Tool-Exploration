## Lesson Objectives
* **Identify** different CI/CD tools available in the market
* **Compare** and contrast CircleCI, GitLab CI/CD, Jenkins, and Azure DevOps
* **Select** the appropriate CI/CD tool based on project requirements
* **Recognise** the similarities and differences in CI/CD configurations across tools

## Lesson Plan

| Duration | What | How or Why |
|----------|------|------------|
| 10 min | Warm up | Intro and lesson overview, recap CI/CD concepts from Lesson 4.7 |
| 20 min | Part 1: CI/CD tool landscape | Why multiple tools exist, categories of CI/CD tools |
| 30 min | Part 2: Comparing four CI/CD tools | CircleCI, GitLab CI/CD, Jenkins, Azure DevOps — pros, cons, use cases, config examples |
| 10 min | Activity 1 — Tool matching discussion | Learners match tools to scenarios based on Part 2 comparisons |
| 50 min | Part 3: GitLab CI/CD demo | Instructor-led demo — Spring Boot app, GitLab pipeline setup, push and watch pipeline run |
| 25 min | Part 4: Tool selection activity | Small groups work through 4 company scenario cards and justify CI/CD tool choices |
| 15 min | Part 5: When to switch CI/CD tools | Signs to switch, migration considerations |
| 10 min | Recap and wrap up | Key takeaways, Q&A |
| **Total** | | **170 min — allows ~10 min buffer** |
